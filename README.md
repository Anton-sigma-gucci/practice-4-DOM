# Практична робота №4 — DOM

https://anton-sigma-gucci.github.io/practice-4-DOM/

## Опис
Практична робота присвячена роботі з JavaScript та DOM (Document Object Model).

Мета роботи — ознайомитися з принципами взаємодії JavaScript із HTML-документом, навчитися знаходити HTML-елементи, змінювати їхній вміст і стилі, а також обробляти події користувача.


## Використані технології
- HTML5
- CSS3
- JavaScript
